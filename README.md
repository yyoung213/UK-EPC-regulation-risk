# 영국 상업용 건물 EPC 규제 리스크의 기대손실 기반 우선순위

영국은 2027년 4월부터 상업용 임대 건물의 최소 에너지 효율 기준(MEES)을 EPC **E등급에서 C등급**으로 올립니다. 기준에 못 미치는 건물은 임대가 막히고 벌금을 물게 됩니다. 제한된 예산으로 모든 건물을 고칠 수 없는 건물주가 **"어떤 건물을 먼저 고쳐야 손실을 가장 많이 줄이는가"**를 판단하도록, 건물별 규제 위험 확률을 예측하고 벌금·임대손실·개보수비를 결합한 **기대손실**로 우선순위를 매겼습니다.

경희대학교 빅데이터 애널리틱스(26-1) C조 · 김민섭, 문하진, 오동진, 이유진, 임효신, 조준혁

- 📊 발표자료: [`발표자료/최종 발표자료.pdf`](발표자료/최종%20발표자료.pdf) (중간본: [`발표자료/중간 발표자료.pdf`](발표자료/중간%20발표자료.pdf))

## 핵심 결과

```
E[손실] = P(EPC 위험) × (벌금 + x/12 × RV + 개보수비)
```

- **위험 확률 모델:** XGBoost, 봉인 Test AUC 0.830 (CV 0.831), 임계값 0.29에서 Recall 0.70 · Precision 0.49
- **우선순위 효과:** 상위 10% 건물(약 1.2만 건)만 대응할 때 회피하는 기대손실

| 우선순위 전략 | 상위 10% | 상위 20% |
|---|---|---|
| **모델 (확률 × 손실금액)** | **£2.72B** | **£3.27B** |
| 손실금액순 (확률 미반영) | £2.14B | £2.79B |
| 규모(RV)순 | £1.80B | £2.48B |
| 위험확률순 | £0.92B | £1.72B |
| 무작위 | £0.40B | £0.81B |

→ 같은 예산으로 위험확률순의 약 **3배**, 무작위의 약 **6.8배**를 막습니다. 위험률과 기대손실 순위는 거의 무관(상관 −0.08)해서, **손실 규모가 1차 결정자이고 위험률은 등급 안의 미세조정**입니다.

## 방법

1. **데이터:** GOV.UK 비주거 건물 EPC 122,634건 × 39변수, VOA 비주거 평가 목록(RV, 연간 임대가치), IMD 지역 박탈지수, ONS 지역 분류
2. **타깃:** EPC A~C = 0(안전), D~G = 1(위험), 위험군 약 22.7%
3. **Leakage 제거:** 배출량·벤치마크·에너지 값처럼 EPC 등급 계산과 직접 연결된 변수를 빼고 건물 기본 특성 8개만 사용
4. **RV 결합:** 두 데이터에 공통 식별자가 없어 우편번호 단위 ㎡당 평균 임대가치(ΣRV ÷ Σ면적)로 매칭
5. **모델링:** 지자체는 fold 내부 Target Encoding(스무딩 α=10), 층화 80/20 분할 후 Test 봉인, Train 5-fold CV로 Logistic · RandomForest · XGBoost 비교
6. **임계값:** 위험 건물을 놓치는 비용(FN)이 더 커서 Recall ≥ 0.70을 보장하는 선에서 Precision 최대(0.29)
7. **손실 공식:** 벌금(RV×10%/20%, 상한 £50k/£150k), 임대손실(단기 3개월·장기 6개월), 개보수비(Savills 단가 + 위험률이 비슷한 이웃 건물 기반 KNN 보정)
8. **지역 분석:** 지역별 지도, 위험 × 손실 의사결정 매트릭스, ONS 분류 대조, 지자체 K-means 2단계(4분면 검증 66% 일치 → PCA 후 5유형)
9. **활용 시나리오:** 런던·콘월 가상 투자자의 £250,000 예산 개보수 — RV 우선 대비 기대손실 우선이 손실을 1.9배·3.6배 더 막음

## 실행

R 스크립트를 열고 실행하면 `최종_데이터셋` 폴더를 자동으로 찾고, 필요한 패키지가 없으면 설치합니다.

```bash
cd 최종/최종_R스크립트
Rscript EPC_기대손실_분석_전체.R
```

결과는 스크립트 옆 `outputs/`(figures · tables · clustering · model)에 저장됩니다.

## 한계

- 개보수비는 실제 견적이 아닌 추정치이고, RV는 실제 임대료의 대리변수입니다.
- 위험 확률은 예측값이라 오차가 있어, 기대손실은 **절대 금액보다 포트폴리오 안의 상대적 우선순위**로 해석해야 합니다.
